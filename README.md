# TechSRIJAN'27 — The Awakening Begins 🚀

The official launch portal for **TechSRIJAN'27**, the Annual Technical Festival of Madan Mohan Malaviya University of Technology (MMMUT), Gorakhpur.

Organized by:
- **IEEE Student Branch (MMMUT)**
- **SAE Collegiate Club (MMMUT)**
- **Technical Sub Council (TSC), Council of Student Activities (CSA)**

---

## 🌟 Key Features

- **Cinematic Atmospheric Visuals**: Dynamic Rising Embers canvas engine and responsive golden aura effects.
- **Dignitary Medallions**: Golden cameos representing the Vice Chancellor, Dean, Chief Guests, and Faculty Incharges.
- **Interactive Launch Countdown**: Flowing neon beam CTA button with modal timer and celebration sequence.
- **Web Audio FX**: Synthesized cinematic brass horn and atmospheric audio drone built on Web Audio API.
- **Responsive Layout**: Tailored for all viewports from mobile to ultra-wide desktop displays.

---

## 🛠️ Tech Stack

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Canvas-Confetti**

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Local Development
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

## 🌐 Deployment

Ready for zero-config deployment on **Vercel**, **Netlify**, or **GitHub Pages**:
